# Miguel Cosme Costa — Portfólio

Portfólio pessoal desenvolvido para apresentar meus projetos, habilidades e serviços na área de desenvolvimento web.

O projeto foi pensado para transmitir minha identidade profissional, apresentar minhas experiências e facilitar o contato com pessoas e empresas interessadas em soluções digitais.

## Sobre o projeto

Este portfólio reúne informações sobre minha trajetória como desenvolvedor web, as tecnologias com as quais trabalho e alguns dos projetos que desenvolvi.

A proposta é oferecer uma experiência moderna, intuitiva e responsiva, com atenção especial ao design, à organização do conteúdo e à performance.

## Tecnologias utilizadas

- **React** — Construção da interface.
- **Vite** — Ferramenta de desenvolvimento e build.
- **Tailwind CSS** — Estilização e responsividade.
- **JavaScript** — Lógica e interatividade.
- **Framer Motion** — Animações e transições.
- **Three.js** — Elementos e experiências 3D.

## Funcionalidades

- Design moderno com identidade visual personalizada.
- Layout responsivo para diferentes dispositivos.
- Apresentação pessoal e profissional.
- Seção de serviços e soluções oferecidas.
- Galeria de projetos com tecnologias utilizadas.
- Apresentação das etapas de desenvolvimento.
- Perguntas frequentes.
- Links para redes sociais e canais de contato.
- Animações e elementos visuais interativos.
- Configuração centralizada do conteúdo do site.

## Personalização

O conteúdo do portfólio é organizado em um único arquivo de configuração, permitindo modificar textos, imagens, links, serviços, projetos e outras informações sem precisar alterar os componentes da aplicação.

Essa abordagem facilita futuras atualizações e mantém o projeto organizado.

## Como executar localmente

**1. Clone o repositório**

```bash
git clone https://github.com/seuusuario/seu-repositorio.git
```

**2. Entre na pasta do projeto**

```bash
cd seu-repositorio
```

**3. Instale as dependências**

```bash
npm install
```

**4. Inicie o servidor de desenvolvimento**

```bash
npm run dev
```

**5. Gere a versão de produção**

```bash
npm run build
```

Os arquivos finais serão gerados na pasta `dist`.
